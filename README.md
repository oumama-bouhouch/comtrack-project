# ComTrack

### Commercial Opportunity Management Web Application

ComTrack is a web application developed during my internship at **Microdata, Casablanca**.  
The application is designed to manage and monitor commercial opportunities through a centralized platform.

## Objectives

- Manage clients and sales representatives
- Create and track commercial opportunities
- Manage activities and follow-ups
- Provide a centralized dashboard
- Facilitate commercial data management

## Technologies

- **Frontend:** Angular
- **Backend:** Java, Spring Boot, REST API
- **Database:** MySQL
- **Tools:** Postman, UML, IntelliJ IDEA, VS Code

## Main Features

- Authentication & registration
- Dashboard
- Client management
- Sales representative management
- Opportunity management
- Activity management

## My Role

**Full-Stack Developer Intern**

I contributed to the design and development of the application, including the database, UML modeling, Angular frontend, Spring Boot backend, REST APIs and MySQL integration.
